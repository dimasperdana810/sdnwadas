Designed and built a web-based application to streamline the scholarship selection process for SD Negeri 3 Wadas. This system functions as a Decision Support System (DSS) to objectively rank candidates based on weighted criteria, ensuring financial aid is distributed to the most eligible students.

Key Contributions:
• Backend Logic: Developed the scoring and ranking algorithm using PHP to process candidate data automatically.
• Database Design: Architected a MySQL database to manage student records, selection criteria, and historical data efficiently.
• Frontend Interactivity: Built a responsive administrative dashboard using JavaScript for ease of use by school staff.
• Impact: Reduced manual data processing time and increased transparency in the selection process.

Tech Stack: PHP, MySQL, JavaScript, HTML/CSS.
